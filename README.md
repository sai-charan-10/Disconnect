# Disconnect - Personal Chat Application

## Overview
This personal chat application allows users to register, authenticate, and engage in real-time communication with other users on the platform. The application is built with modern web technologies to ensure a dynamic, responsive, and secure user experience.

## Technologies Used

### Frontend
- **React.js**: Built the user interface with dynamic and responsive components to provide an engaging user experience.
- **HTML5 and CSS3**: Designed and styled the layout, maintaining modern web standards and enhancing accessibility.
- **React Hooks and Context API**: Implemented for state management to streamline state updates and improve application performance.
- **WebSocket**: Integrated for real-time messaging, enabling instantaneous communication between users.

### Backend
- **PHP**: Developed the server-side logic, employing object-oriented design principles to create a modular and maintainable codebase.
- **RESTful APIs**: Designed and implemented for user registration, authentication, and message handling, ensuring secure and efficient data interactions.
- **MySQL**: Designed the database schema with a focus on normalization to maintain data integrity and optimize query performance. Implemented SQL transactions to ensure consistency during complex operations.

### Security
- **Input Validation and Sanitization**: Applied to prevent SQL injection and cross-site scripting (XSS) vulnerabilities.
- **HTTPS**: Utilized to secure data transmission, ensuring end-to-end encryption and protection of user information.

## Features
- **User Registration and Authentication**: Allows users to create accounts and securely log in to the application.
- **Real-Time Messaging**: Enables users to communicate instantaneously using WebSocket.
- **Dynamic User Interface**: React-based UI with state management using React Hooks and Context API.
- **RESTful APIs**: Secure and efficient handling of user data and messaging.
- **Database Management**: MySQL database designed for data integrity and optimized performance.
- **Security Measures**: Input validation, sanitization, and HTTPS for secure data handling.
